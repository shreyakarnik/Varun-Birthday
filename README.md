# Varun Birthday Site

This is a ready-to-upload Netflix-style desktop website. You do not need to install anything.

## Add the video

Put Varun's background video in the `videos` folder and name it:

```text
varun-bg.mp4
```

For the Netflix-style player that opens when you click Play, add another video:

```text
varun-player.mp4
```

The page will still open without either video, but the videos are what give it the Netflix feel.

## Preview it

Double-click `index.html`.

## Put it on GitHub

1. Go to https://github.com/new
2. Repository name: `varun-birthday`
3. Choose `Public`
4. Click `Create repository`
5. Click `uploading an existing file`
6. Upload `index.html`, `README.md`, `.gitignore`, and the `videos` folder
7. Click `Commit changes`
8. Go to `Settings` -> `Pages`
9. Under `Build and deployment`, choose `Deploy from a branch`
10. Under `Branch`, choose `main` and `/root`, then click `Save`

After a minute or two, your site will be here:

```text
https://YOUR-GITHUB-USERNAME.github.io/varun-birthday/
```
